# DFSASimulator
Simulador DFSA para cadeira SISCOM módulo RFID

## Visualização online

Uma versão interativa do simulador (portada para JavaScript) fica em `docs/` e é publicada no GitHub Pages:
**https://lapprand.github.io/DFSASimulator/**

- Passo a passo de uma identificação, mostrando os slots vazios, com sucesso e em colisão de cada frame.
- Comparação dos estimadores Lower Bound, Eom-Lee e Algoritmo Q (total de slots, vazios, colisões, frames e eficiência).

Para rodar localmente: `cd docs && python3 -m http.server` e abra http://localhost:8000.
