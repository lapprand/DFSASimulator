Simulador DFSA

Anticolisão RFID com Dynamic Framed Slotted ALOHA. O leitor abre um frame com L slots, cada etiqueta responde em um slot aleatório e, a partir do número de slots vazios, com sucesso e em colisão, um estimador decide o tamanho do próximo frame. O processo se repete até todas as etiquetas serem identificadas.

Projeto da disciplina SISCOM (módulo RFID). Esta página roda o mesmo algoritmo do código Java, portado para JavaScript, direto no navegador.

3. Os estimadores

Lower Bound
Cada slot em colisão tem pelo menos 2 etiquetas, então o próximo frame é L = 2 · c, onde c é o número de colisões. Simples, mas subestima quando há muitas etiquetas.
Eom-Lee
Estima iterativamente γ (etiquetas por colisão) até convergir: β = L / (γ·c + s), γ = (1 − e−1/β) / (β·(1 − (1 + 1/β)·e−1/β)). O próximo frame é γ · c.
Algoritmo Q (EPC Gen2)
Em vez de frames inteiros, ajusta um valor Q a cada slot: diminui C = 0,2 em slot vazio, aumenta em colisão; cada etiqueta responde com probabilidade 1/2Q. Aqui cada slot conta como um "frame".
Eficiência
Slots com sucesso ÷ total de slots. O máximo teórico do Framed ALOHA é 1/e ≈ 36,8%, atingido quando L ≈ número de etiquetas.
